# Project Summary
LOBOKO is a mobile-first social networking platform designed to connect clients with service providers. It allows users to discover talents, share experiences, and communicate through private messaging. The platform utilizes Supabase for authentication, database management, and storage, and is optimized for deployment on Vercel. Recent enhancements include support for multimedia messaging, a global incoming call system, improved user interactions, and a redesigned professional homepage, along with an advertising carousel for sponsored content and a new rating system for evaluating service providers.

# Project Module Description
- **Authentication**: User onboarding with email/password registration via Supabase, including role selection (client or service provider) and profile management.
- **Feed**: Displays user posts with options to like and comment, now supports multimedia content.
- **Discovery**: Search functionality for service providers and clients, now includes ratings.
- **Messaging**: Real-time private messaging with support for multimedia (images and videos), including voice and video calls, with an unread messages badge.
- **Media Handling**: New components for media selection, preview, and messaging.
- **Profile Management**: Edit profiles and view average ratings for service providers.
- **Notifications**: Real-time notifications for likes, comments, and messages.
- **Settings**: Theme customization and account management options.
- **Layout**: Overall page structure and appearance management.
- **Menu**: Centralized navigation with logout confirmation dialogues.
- **Call System**: Global incoming call system with real-time synchronization.
- **Hero Banner**: Professional design showcasing the platform's value proposition.
- **Ads Carousel**: Displays sponsored advertisements below the HeroBanner.
- **Rating System**: Clients can rate service providers, with average ratings shown on profiles.
- **Comments Module**: Manages user comments on posts with error logging and setup instructions.

# File Description Inventory
- `app/frontend/src/App.tsx`: Main application component, updated for new routes and global call handling.
- `app/frontend/src/pages/*`: Various page components, including Discover and UserProfile.
- `app/frontend/src/components/*`: Updated reusable UI components, including multimedia handling.
- `app/frontend/src/lib/supabase.ts`: Configures the Supabase client.
- `app/frontend/src/lib/notifications.ts`: Functions for managing notifications.
- `app/frontend/src/lib/storage-helpers.ts`: Functions for media management, including upload and URL resolution.
- `app/frontend/src/pages/Messages.tsx`: Messaging functionality, now includes multimedia support.
- `app/frontend/src/pages/Profile.tsx`: User profile management.
- `app/frontend/src/contexts/PresenceContext.tsx`: Manages user online status and typing indicators.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
