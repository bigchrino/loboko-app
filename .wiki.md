# Project Summary
LOBOKO is a mobile-first social networking platform that connects clients with service providers, enabling users to discover talents, share experiences, and engage in private messaging. It utilizes Supabase for authentication and database management, hosted on Vercel. Recent updates have introduced a marketplace feature that includes provider works, service requests, and favorites, enhancing user engagement. Key improvements focus on user navigation, real-time notifications, and a refined user interface for discovering and managing services.

# Project Module Description
- **Authentication**: User onboarding via Supabase, including email/password registration, role selection (client or service provider), and profile management.
- **Feed**: Displays user posts with multimedia support, likes, comments, and timestamps, now includes clickable post frames.
- **Marketplace**: New features include:
  - **Provider Works**: Users can create and view works with pagination and lazy loading.
  - **Service Requests**: Clients can publish service requests with anti-spam measures.
  - **Favorites**: Users can save providers, works, and services with easy management options.
- **Messaging**: Real-time messaging with multimedia support, including group chats and direct messages.
- **Media Handling**: Enhanced media selection and messaging components with lazy loading.
- **Profile Management**: Comprehensive profile editing for service providers, including portfolio management.
- **Notifications**: Real-time notifications for user interactions.
- **Settings**: Customization options for themes and notifications.
- **Recommendations**: Displays top-rated and available service providers based on user interactions.

# File Description Inventory
- `app/frontend/src/App.tsx`: Main application component, updated for new routes and marketplace features.
- `app/frontend/src/pages/Works.tsx`: Page component for displaying provider works with pagination and lazy loading.
- `app/frontend/src/pages/ServiceRequests.tsx`: Page component for managing service requests with anti-spam measures.
- `app/frontend/src/pages/Favorites.tsx`: Page component for managing user favorites across different categories.
- `app/frontend/src/pages/ServiceRequestDetail.tsx`: Page for viewing details and responses of a specific service request.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
