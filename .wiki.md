# Project Summary
LOBOKO is a mobile-first social networking platform designed to connect clients with service providers. It enables users to discover talents, share experiences, and communicate through private messaging. Leveraging Supabase for authentication, database management, and storage, the platform is optimized for deployment on Vercel. Recent enhancements have improved user interactions, including a global incoming call system, upgraded messaging features, a redesigned professional homepage, and an advertising carousel to display sponsored content. A new rating system allows clients to evaluate service providers, further enhancing user engagement.

# Project Module Description
- **Authentication**: User onboarding with email/password registration through Supabase, including role selection (client or service provider) and profile management.
- **Feed**: Displays user posts with options to like and comment.
- **Discovery**: Facilitates searching for service providers and clients by name or profession, now includes ratings for service providers.
- **Messaging**: Enables real-time private messaging between users, including voice and video calls, with a badge for unread messages.
- **Voice Messaging**: Allows users to record and send voice messages, with automatic codec detection and error handling.
- **Video Calling**: Synchronizes call states between users using Supabase Realtime.
- **Profile Management**: Users can edit profiles, including avatars and bios, and view average ratings for service providers.
- **Notifications**: Notifies users about likes, comments, and messages in real-time, with an unread count badge.
- **Settings**: Options for theme customization and account management, including logout confirmation.
- **Layout**: Manages the overall structure and appearance of pages.
- **Menu**: Centralized navigation for accessing all sections, now includes logout confirmation dialogues.
- **Call System**: A global incoming call system allowing users to receive call invites from any page, with real-time synchronization of call states.
- **Hero Banner**: Component on the homepage showcasing a professional design with a clear value proposition and trust signals.
- **Ads Carousel**: A lightweight component displaying sponsored advertisements below the HeroBanner on the homepage.
- **Rating System**: Allows clients to rate service providers, displaying average ratings and total reviews on profiles.
- **Comments Module**: Manages user comments on posts, now includes detailed error logging and setup instructions for Supabase.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
