# Project Summary
LOBOKO is a mobile-first social networking platform designed to connect clients with service providers. It enables users to discover talents, share experiences, and communicate through private messaging. The platform utilizes Supabase for authentication and database management, and is optimized for deployment on Vercel. Recent enhancements focus on user engagement with features such as unread message badges, multimedia messaging, and a global call system. The latest updates improve video call stability and address issues with voice note sending on Android browsers.

# Project Module Description
- **Authentication**: User onboarding with email/password registration via Supabase, including role selection (client or service provider) and profile management.
- **Feed**: Displays user posts with options to like and comment, supports multimedia content, and shows the time since publication.
- **Discovery**: Search functionality for service providers and clients, including ratings.
- **Messaging**: Real-time private messaging with multimedia support, including voice and video calls, conversation archiving, blocking, reporting features, and group messaging capabilities. Includes unread message badges.
- **Media Handling**: Components for media selection, preview, and messaging.
- **Profile Management**: Edit profiles and view average ratings for service providers.
- **Notifications**: Real-time notifications for likes, comments, messages, and new social notifications for post shares and comment interactions.
- **Settings**: Theme customization and account management options.
- **Layout**: Overall page structure and appearance management.
- **Menu**: Centralized navigation with logout confirmation dialogues.
- **Call System**: Global incoming call system with real-time synchronization, enhanced reliability, and improved video handling through TURN server support.
- **Hero Banner**: Professional design showcasing the platform's value proposition.
- **Ads Carousel**: Displays sponsored advertisements below the Hero Banner.
- **Rating System**: Clients can rate service providers, with average ratings shown on profiles.
- **Comments Module**: Enhanced comments management with likes, replies, emoji support, and ownership-based options for comment actions.
- **Groups**: Feature allowing users to create groups, manage members, and send group messages, including reactions and media sharing.
- **Profile Quick Access**: Avatar button in the mobile navbar for quick access to user profiles.
- **Voice Recorder**: Updated component for sending voice notes, ensuring visibility of audio controls and action buttons on all devices.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
