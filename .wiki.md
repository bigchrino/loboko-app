# Project Summary
LOBOKO is a mobile-first social networking platform that connects clients with service providers. Users can discover talents, share experiences, and communicate through private messaging. Built on Supabase for authentication and database management, the platform is optimized for Vercel deployment. Recent enhancements include multimedia messaging, a global incoming call system, improved user interactions, and a comprehensive comments system. New features now support conversation archiving, blocking users, and reporting, further enriching user experience and safety.

# Project Module Description
- **Authentication**: User onboarding with email/password registration via Supabase, including role selection (client or service provider) and profile management.
- **Feed**: Displays user posts with options to like and comment, supports multimedia content, and shows the time since publication.
- **Discovery**: Search functionality for service providers and clients, now includes ratings.
- **Messaging**: Real-time private messaging with multimedia support, including voice and video calls, conversation archiving, blocking, and reporting features.
- **Media Handling**: New components for media selection, preview, and messaging.
- **Profile Management**: Edit profiles and view average ratings for service providers.
- **Notifications**: Real-time notifications for likes, comments, messages, and new social notifications for post shares and comment interactions.
- **Settings**: Theme customization and account management options.
- **Layout**: Overall page structure and appearance management.
- **Menu**: Centralized navigation with logout confirmation dialogues.
- **Call System**: Global incoming call system with real-time synchronization.
- **Hero Banner**: Professional design showcasing the platform's value proposition.
- **Ads Carousel**: Displays sponsored advertisements below the HeroBanner.
- **Rating System**: Clients can rate service providers, with average ratings shown on profiles.
- **Comments Module**: Enhanced comments management with likes, replies, emoji support, and ownership-based options for comment actions.

# File Description Inventory
- `app/frontend/src/App.tsx`: Main application component, updated for new routes and global call handling.
- `app/frontend/src/pages/*`: Various page components, including Discover, UserProfile, Messages, and ContactInfo.
- `app/frontend/src/components/*`: Updated reusable UI components, including multimedia handling, post time display, and new conversation menu.
- `app/frontend/src/lib/supabase.ts`: Configures the Supabase client.
- `app/frontend/src/lib/notifications.ts`: Functions for managing notifications, including new social types.
- `app/frontend/src/lib/storage-helpers.ts`: Functions for media management, including upload and URL resolution.
- `app/frontend/src/lib/format-time.ts`: Utility for formatting post timestamps.
- `app/frontend/src/lib/message-format.ts`: Helpers for encoding and decoding message payloads.
- `app/frontend/src/contexts/PresenceContext.tsx`: Manages user online status and typing indicators.
- `app/frontend/src/components/ConfirmDialog.tsx`: Component for managing confirmation dialogs for sensitive actions.
- `app/frontend/src/components/ConversationMenu.tsx`: Component for managing conversation options (archive/delete/block).
- `app/frontend/src/pages/ContactInfo.tsx`: Displays details about a contact when accessed from a conversation.
- `app/frontend/src/pages/Messages.tsx`: Messaging functionality, now includes a search bar, archived conversations, and new conversation controls.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
