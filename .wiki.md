# Project Summary
LOBOKO is a social networking platform designed to connect clients with service providers. It enables users to discover talents, share experiences, and communicate through private messaging, all while prioritizing a mobile-first approach for superior accessibility. Recent enhancements include the migration from Atoms Cloud to Supabase, streamlining authentication, database management, and storage solutions. This shift aims to simplify deployment on Vercel and improve user experience by eliminating unnecessary redirection and authorization screens.

# Project Module Description
- **Authentication**: Manages user onboarding with email/password registration through Supabase, including role selection (client or service provider) and profile management.
- **Feed**: Displays user posts with options to like and comment.
- **Discovery**: Facilitates searching for service providers and clients by name or profession.
- **Messaging**: Enables real-time private messaging between users.
- **Profile Management**: Allows users to edit profiles, including avatars and bios.
- **Notifications**: Informs users about likes, messages, and activities.
- **Settings**: Provides options for theme customization and account management, including logout confirmation.
- **Layout**: Manages the overall structure and appearance of pages.
- **Menu**: Centralized navigation for accessing all sections, now includes logout confirmation dialogues.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
