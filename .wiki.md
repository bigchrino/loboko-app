# Project Summary
LOBOKO is a mobile-first social networking platform that connects clients with service providers. Users can discover talents, share experiences, and communicate through private messaging. The platform is built on Supabase for authentication and database management, optimized for Vercel deployment. Recent enhancements include multimedia messaging, a global incoming call system, improved user interactions, and a comprehensive comments system. Key features now support conversation archiving, user blocking, reporting, and a new group messaging system that allows users to create groups, add members, and manage group interactions.

# Project Module Description
- **Authentication**: User onboarding with email/password registration via Supabase, including role selection (client or service provider) and profile management.
- **Feed**: Displays user posts with options to like and comment, supports multimedia content, and shows the time since publication.
- **Discovery**: Search functionality for service providers and clients, now includes ratings.
- **Messaging**: Real-time private messaging with multimedia support, including voice and video calls, conversation archiving, blocking, reporting features, and group messaging capabilities.
- **Media Handling**: Components for media selection, preview, and messaging.
- **Profile Management**: Edit profiles and view average ratings for service providers.
- **Notifications**: Real-time notifications for likes, comments, messages, and new social notifications for post shares and comment interactions.
- **Settings**: Theme customization and account management options.
- **Layout**: Overall page structure and appearance management.
- **Menu**: Centralized navigation with logout confirmation dialogues.
- **Call System**: Global incoming call system with real-time synchronization.
- **Hero Banner**: Professional design showcasing the platform's value proposition.
- **Ads Carousel**: Displays sponsored advertisements below the HeroBanner.
- **Rating System**: Clients can rate service providers, with average ratings shown on profiles.
- **Comments Module**: Enhanced comments management with likes, replies, emoji support, and ownership-based options for comment actions.
- **Groups**: New feature allowing users to create groups, manage members, and send group messages, including reactions and media sharing.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
