# Project Summary
LOBOKO is a mobile-first social networking platform designed to connect clients with service providers. Users can discover talents, share experiences, and engage in private messaging. The platform utilizes Supabase for authentication and database management, and is optimized for deployment on Vercel. Recent updates have introduced a service category system, enhancing the onboarding experience for service providers by requiring them to select from predefined categories rather than entering free text. This change aims to streamline service offerings and improve user experience. Additional features include improved group chat functionalities, a voice messaging player, and a notification system for missed calls.

# Project Module Description
- **Authentication**: User onboarding via Supabase with email/password registration, role selection (client or service provider), and profile management.
- **Feed**: Displays user posts with multimedia support, likes, comments, and timestamps.
- **Discovery**: Search functionality for service providers and clients, including ratings and a new service category feature.
- **Messaging**: Real-time private messaging with multimedia support, group messaging, conversation management features, emoji support, and @mentions functionality.
- **Media Handling**: Components for media selection and messaging, including a fixed media picker for private conversations.
- **Profile Management**: Profile editing with new service category selection for service providers.
- **Notifications**: Real-time notifications for various interactions, including alerts for incoming calls and missed calls.
- **Settings**: Theme customization and account management options.
- **Layout**: Overall page structure and appearance management.
- **Menu**: Centralized navigation with logout confirmation dialogues and updated to include missed calls and statuses.
- **Call System**: Global incoming call system with real-time synchronization, call history, and improved video handling.
- **Hero Banner**: Professional design showcasing the platform's value proposition.
- **Ads Carousel**: Displays sponsored advertisements with links to service categories.
- **Rating System**: Clients can rate service providers, with average ratings shown on profiles.
- **Comments Module**: Enhanced comments management with various interaction options and @mentions support.
- **Groups**: Feature for creating and managing groups with messaging capabilities, including @mentions.
- **Profile Quick Access**: Avatar button for quick access to user profiles.
- **Voice Recorder**: Updated component for sending voice notes with improved controls and playback features.
- **Voice Message**: New voice messaging player with features such as reliable play/pause, clear progress visualization, drag seek, replay options, and cross-platform support.
- **Statuses**: New feature for creating and viewing temporary status updates, allowing users to share short messages, images, or videos that expire after 24 hours.
- **Emoji Picker**: New component for adding emojis during status creation and replies, enhancing user interactions.
- **Mention System**: Updated to allow clicking on @mentions to navigate to user profiles, with error handling for non-existent profiles.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
