# Project Summary
LOBOKO is a social networking platform designed to connect clients with service providers. It enables users to discover talents, share experiences, and communicate through private messaging. The application features a modern, mobile-first design, ensuring accessibility and ease of use. Recent updates include a refined header displaying only the logo for a cleaner user interface.

# Project Module Description
- **Authentication**: Handles user onboarding, role selection, and profile management.
- **Feed**: Displays user posts with options to like and comment.
- **Discovery**: Facilitates searching for service providers and clients by name or profession.
- **Messaging**: Enables real-time private messaging between users.
- **Profile Management**: Allows users to edit profiles, including avatars and bios.
- **Notifications**: Informs users about likes, messages, and activities.
- **Settings**: Provides options for theme customization and account management.
- **Layout**: Manages the overall structure and appearance of pages, now displaying only the logo in the header.

# File Description Inventory
- `app/backend/main.py`: Entry point for the backend application.
- `app/frontend/src/App.tsx`: Main application component for the frontend.
- `app/frontend/src/pages/*`: Various page components for routing and functionality.
- `app/frontend/src/components/*`: Reusable UI components, including the updated `Logo` and `Layout` components.
- `app/frontend/src/lib/*`: Utility libraries for API interactions and storage management.
- `app/frontend/src/index.css`: Global CSS with updated brand colors and styles.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: Atoms Cloud
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Docker (for containerization)

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
