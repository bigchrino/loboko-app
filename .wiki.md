# Project Summary
LOBOKO is a mobile-first social networking platform that connects clients with service providers. Users can discover talents, share experiences, and communicate through private messaging. The platform leverages Supabase for authentication and database management, and is hosted on Vercel. Recent enhancements include a refined onboarding process, improved group chat functionalities, an upgraded voice messaging player, a new Starred Messages feature, and the ability to send document files (PDF, Word, Excel, ZIP) in both private messages and groups. The introduction of a "Last Seen" feature enhances user interaction by displaying activity status.

# Project Module Description
- **Authentication**: User onboarding via Supabase with email/password registration, role selection (client or service provider), and profile management.
- **Feed**: Displays user posts with multimedia support, likes, comments, and timestamps.
- **Discovery**: Search functionality for service providers and clients, including ratings and service categories.
- **Messaging**: Real-time private messaging with multimedia support, group messaging, document file sharing, conversation management features, emoji support, @mentions functionality, and ephemeral messaging.
- **Media Handling**: Components for media selection and messaging, including a fixed media picker for private conversations.
- **Profile Management**: Profile editing with service category selection for service providers, now includes activity status.
- **Notifications**: Real-time notifications for various interactions, including alerts for incoming and missed calls.
- **Settings**: Theme customization and account management options.
- **Layout**: Overall page structure and appearance management.
- **Menu**: Centralized navigation with logout confirmation dialogues and updates to include missed calls and statuses.
- **Call System**: Global incoming call system with real-time synchronization, call history, and improved video handling.
- **Hero Banner**: Professional design showcasing the platform's value proposition.
- **Ads Carousel**: Displays sponsored advertisements with links to service categories.
- **Rating System**: Clients can rate service providers, with average ratings shown on profiles.
- **Comments Module**: Enhanced comments management with various interaction options and @mentions support.
- **Groups**: Feature for creating and managing groups with messaging capabilities, including @mentions and document sharing.
- **Profile Quick Access**: Avatar button for quick access to user profiles.
- **Voice Recorder**: Updated component for sending voice notes with improved controls and playback features.
- **Voice Message**: New voice messaging player with features like reliable play/pause, clear progress visualization, drag seek, replay options, and cross-platform support.
- **Statuses**: Feature for creating and viewing temporary status updates that expire after 24 hours.
- **Emoji Picker**: Component for adding emojis during status creation and replies.
- **Mention System**: Updated to allow clicking on @mentions to navigate to user profiles, with error handling for non-existent profiles.
- **Ephemeral Messaging**: Enhanced feature allowing messages to disappear after a specified duration with real-time synchronization of settings.
- **Ephemeral Badge**: A new component that displays a timer icon on ephemeral messages, showing remaining time in a discreet pop-up when clicked.
- **Ephemeral Cleanup**: New SQL setup for automatic deletion of expired ephemeral messages from the database.
- **Starred Messages**: New feature allowing users to view and manage messages marked as important across private and group conversations.
- **Last Seen Feature**: Displays user activity status such as "Online," "Seen a few minutes ago," or "Seen today," enhancing user interaction.
- **Document Messaging**: New feature for sending document files (PDF, Word, Excel, ZIP) in both private and group messages, including a FilePicker, FileMessage, and FilePreview components.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
