# Project Summary
LOBOKO is a mobile-first social networking platform designed to connect clients with service providers. Users can discover talents, share experiences, and communicate through private messaging. The platform leverages Supabase for authentication and database management, and is optimized for deployment on Vercel. Recent features include a voice messaging player, call history, a notification system for missed calls, and a status feature similar to Instagram Stories, all aimed at enhancing user engagement.

# Project Module Description
- **Authentication**: User onboarding via Supabase with email/password registration, role selection (client or service provider), and profile management.
- **Feed**: Displays user posts with multimedia support, likes, comments, and timestamps.
- **Discovery**: Search functionality for service providers and clients, including ratings.
- **Messaging**: Real-time private messaging with multimedia support, group messaging, and conversation management features.
- **Media Handling**: Components for media selection and messaging.
- **Profile Management**: Profile editing and viewing average ratings for service providers.
- **Notifications**: Real-time notifications for various interactions, including alerts for incoming calls and missed calls.
- **Settings**: Theme customization and account management options.
- **Layout**: Overall page structure and appearance management.
- **Menu**: Centralized navigation with logout confirmation dialogues and updated to include missed calls and statuses.
- **Call System**: Global incoming call system with real-time synchronization, call history, and improved video handling.
- **Hero Banner**: Professional design showcasing the platform's value proposition.
- **Ads Carousel**: Displays sponsored advertisements.
- **Rating System**: Clients can rate service providers, with average ratings shown on profiles.
- **Comments Module**: Enhanced comments management with various interaction options.
- **Groups**: Feature for creating and managing groups with messaging capabilities.
- **Profile Quick Access**: Avatar button for quick access to user profiles.
- **Voice Recorder**: Updated component for sending voice notes with improved controls and playback features.
- **Voice Message**: New voice messaging player with features such as reliable play/pause, clear progress visualization, drag seek, replay options, and cross-platform support.
- **Statuses**: New feature for creating and viewing temporary status updates, allowing users to share short messages, images, or videos that expire after 24 hours.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
