# Project Summary
LOBOKO is a mobile-first social networking platform designed to connect clients with service providers. Users can discover talents, share experiences, and communicate through private messaging. The platform utilizes Supabase for authentication, database management, and storage, and is optimized for deployment on Vercel. Recent updates have added multimedia messaging, a global incoming call system, enhanced user interactions, a redesigned professional homepage, an advertising carousel for sponsored content, and a new rating system for service providers. The latest enhancements include a comprehensive comments system with likes, replies, emoji support, ownership-based comment management, and new social notifications for shares and comment interactions.

# Project Module Description
- **Authentication**: User onboarding with email/password registration via Supabase, including role selection (client or service provider) and profile management.
- **Feed**: Displays user posts with options to like and comment, now supports multimedia content and shows the time since publication.
- **Discovery**: Search functionality for service providers and clients, now includes ratings.
- **Messaging**: Real-time private messaging with support for multimedia (images and videos), including voice and video calls, with an unread messages badge.
- **Media Handling**: New components for media selection, preview, and messaging.
- **Profile Management**: Edit profiles and view average ratings for service providers.
- **Notifications**: Real-time notifications for likes, comments, messages, and now includes new social notifications for post shares, comment likes, and replies.
- **Settings**: Theme customization and account management options.
- **Layout**: Overall page structure and appearance management.
- **Menu**: Centralized navigation with logout confirmation dialogues.
- **Call System**: Global incoming call system with real-time synchronization.
- **Hero Banner**: Professional design showcasing the platform's value proposition.
- **Ads Carousel**: Displays sponsored advertisements below the HeroBanner.
- **Rating System**: Clients can rate service providers, with average ratings shown on profiles.
- **Comments Module**: Enhanced comments management with likes, replies, emoji support, and ownership-based options for comment actions.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
