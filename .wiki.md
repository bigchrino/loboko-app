# Project Summary
LOBOKO is a mobile-first social networking platform designed to connect clients with service providers. Users can discover talents, share experiences, and engage in private messaging. The platform leverages Supabase for authentication and database management, hosted on Vercel. Recent enhancements focus on user experience, including a robust provider profile feature with a portfolio section, advanced search filters, improved media handling, and a new moderation and monetization system.

# Project Module Description
- **Authentication**: User onboarding via Supabase, including email/password registration, role selection (client or service provider), and profile management.
- **Feed**: Displays user posts with multimedia support, likes, comments, and timestamps.
- **Discovery**: Advanced search functionality for service providers and clients, with filters for availability, city, and ratings.
- **Messaging**: Real-time private and group messaging with multimedia support, document sharing, conversation management, emoji support, @mentions, ephemeral messaging, and reporting features.
- **Media Handling**: Components for media selection and messaging, enhanced with lazy loading for improved performance.
- **Profile Management**: Profile editing with service category selection for service providers, including availability status, city, and portfolio management.
- **Notifications**: Real-time notifications for various interactions, including alerts for incoming and missed calls, and push notifications for messages.
- **Settings**: Theme customization and account management options, including push notification preferences.
- **Layout**: Overall page structure and appearance management.
- **Menu**: Centralized navigation with logout confirmation dialogues and updates to include missed calls and statuses.
- **Call System**: Global incoming call system with real-time synchronization, call history, and improved video handling.
- **Hero Banner**: Professional design showcasing the platform's value proposition.
- **Ads Carousel**: Displays sponsored advertisements with links to service categories.
- **Rating System**: Clients can rate service providers, with average ratings shown on profiles.
- **Comments Module**: Enhanced comments management with various interaction options and @mentions support.
- **Groups**: Feature for creating and managing groups with messaging capabilities, including @mentions and document sharing.
- **Portfolio Management**: Features for service providers to upload and manage a portfolio of work samples, including images and videos.
- **Status Updates**: Feature for creating and viewing temporary status updates that expire after 24 hours.
- **Moderation System**: Allows users to report inappropriate content, with unique constraints to prevent spam.
- **Monetization System**: Introduces a premium subscription model for service providers with specific handling for subscription types.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
