# Project Summary
LOBOKO is a mobile-first social networking platform designed to connect clients with service providers. Users can discover talents, share experiences, and communicate through private messaging. The platform utilizes Supabase for authentication, database management, and storage, enhancing user experience with optimized deployment on Vercel. Recent updates have introduced real-time messaging, notifications, and voice messaging capabilities, allowing users to send and receive audio notes seamlessly.

# Project Module Description
- **Authentication**: Manages user onboarding with email/password registration through Supabase, including role selection (client or service provider) and profile management.
- **Feed**: Displays user posts with options to like and comment.
- **Discovery**: Facilitates searching for service providers and clients by name or profession.
- **Messaging**: Enables real-time private messaging between users, including voice and video calls, with a badge for unread messages.
- **Voice Messaging**: New feature allowing users to record and send voice messages, with automatic codec detection and error handling.
- **Profile Management**: Allows users to edit profiles, including avatars and bios.
- **Notifications**: Notifies users about likes, comments, and messages in real-time, with an unread count badge.
- **Settings**: Provides options for theme customization and account management, including logout confirmation.
- **Layout**: Manages the overall structure and appearance of pages.
- **Menu**: Centralized navigation for accessing all sections, now includes logout confirmation dialogues.

# Technology Stack
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Vercel

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
