# Project Summary
LOBOKO is a social networking platform designed to connect clients with service providers. It allows users to discover talents, share experiences, and communicate through private messaging. The application features a modern, mobile-first design for enhanced accessibility and user experience. Recent updates have introduced a custom email/password authentication system, allowing users to create accounts independently from Atoms, along with streamlined onboarding processes and improved user interface elements.

# Project Module Description
- **Authentication**: Manages user onboarding with email/password registration, role selection (client or service provider), and profile management.
- **Feed**: Displays user posts with options to like and comment.
- **Discovery**: Facilitates searching for service providers and clients by name or profession.
- **Messaging**: Enables real-time private messaging between users.
- **Profile Management**: Allows users to edit profiles, including avatars and bios.
- **Notifications**: Informs users about likes, messages, and activities.
- **Settings**: Provides options for theme customization and account management, including logout confirmation.
- **Layout**: Manages the overall structure and appearance of pages.
- **Menu**: Centralized navigation for accessing all sections.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: Atoms Cloud
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Docker (for containerization)

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
