# Project Summary
LOBOKO is a social networking platform designed to connect clients and service providers. It allows users to discover talents, share experiences, and communicate seamlessly through private messaging. The application features a modern design with a mobile-first approach, ensuring accessibility and ease of use for all users.

# Project Module Description
- **Authentication**: Handles user onboarding, role selection, and profile management.
- **Feed**: Displays posts from users, allowing for likes and comments.
- **Discovery**: Facilitates searching for service providers and clients by name or profession.
- **Messaging**: Enables real-time private messaging between users.
- **Profile Management**: Allows users to edit their profiles, including avatars and bios.
- **Notifications**: Keeps users updated on likes, messages, and other activities.
- **Settings**: Provides options for theme customization and account management.

# File Description Inventory
- `app/backend/main.py`: Entry point for the backend application.
- `app/frontend/src/App.tsx`: Main application component for the frontend.
- `app/frontend/src/pages/*`: Various page components for routing and functionality.
- `app/frontend/src/components/*`: Reusable UI components.
- `app/frontend/src/lib/*`: Utility libraries for API interactions and storage management.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: Atoms Cloud
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Docker (for containerization)

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
