# Project Summary
LOBOKO is a social networking platform aimed at connecting clients with service providers. It allows users to discover talents, share experiences, and communicate seamlessly through private messaging. The application features a modern, mobile-first design, ensuring accessibility and ease of use for all users. Recent updates have integrated the official LOBOKO logo and updated the brand colors to enhance the user experience.

# Project Module Description
- **Authentication**: Manages user onboarding, role selection, and profile management.
- **Feed**: Displays user posts, enabling likes and comments.
- **Discovery**: Allows searching for service providers and clients by name or profession.
- **Messaging**: Supports real-time private messaging between users.
- **Profile Management**: Users can edit profiles, including avatars and bios.
- **Notifications**: Keeps users informed about likes, messages, and activities.
- **Settings**: Offers options for theme customization and account management.

# File Description Inventory
- `app/backend/main.py`: Entry point for the backend application.
- `app/frontend/src/App.tsx`: Main application component for the frontend.
- `app/frontend/src/pages/*`: Various page components for routing and functionality.
- `app/frontend/src/components/*`: Reusable UI components, including the new `Logo` component.
- `app/frontend/src/lib/*`: Utility libraries for API interactions and storage management.
- `app/frontend/src/index.css`: Global CSS with updated brand colors and styles.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: Atoms Cloud
- **State Management**: React Context API
- **Routing**: React Router
- **Deployment**: Docker (for containerization)

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```

2. **Build the Project**:
   ```bash
   pnpm run build
   ```

3. **Run the Application**:
   ```bash
   pnpm run start
   ```
