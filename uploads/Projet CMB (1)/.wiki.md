# Project Summary
LOBOKO is a modern multi-page web application that connects users with qualified professionals for various services such as plumbing, electrical work, moving, hairdressing, and repairs. The platform prioritizes user engagement through a sleek, dark-themed, mobile-first interface. Recent updates include an interactive chat feature, a robust backend for real-time messaging, and a comprehensive settings page for user customization. The latest addition is a complete user profile page that enhances user interaction and personalization.

# Project Module Description
- **Accueil**: Homepage featuring stories, a welcome banner, quick categories, and a news feed.
- **Découverte**: Explore new content and trends with a search bar.
- **Messages**: Interface for viewing conversations and accessing the chat feature.
- **Suggestion**: Personalized content suggestions based on user preferences.
- **Entreprise**: Company information with job offers and services.
- **Notifications**: User notifications displayed prominently.
- **Panier**: Shopping cart for managing future purchases.
- **Urgences**: Quick access to emergency services.
- **Profil**: Complete user profile management with statistics, posts, and customization options.
- **Menu**: Navigation with logout options.
- **Chat**: Interactive chat page for messaging with service providers.
- **Paramètres**: Comprehensive settings page for account preferences, privacy, security, notifications, and appearance.

# Usage
To set up the project:
1. Clone the repository.
2. Navigate to the `app/frontend` directory.
3. Install dependencies using `pnpm install`.
4. Build the project with `pnpm run build`.
5. Open `index.html` in a web browser to view the application.
